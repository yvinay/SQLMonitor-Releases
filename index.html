The query behind the problem, and why

When CPU, IO or log writes spike, the advisor names the few queries responsible and their share of the load, reads their execution plans, and explains the cause in plain language.

  • Implicit conversions, large scans, key lookups, spills, memory grants
  • Plan regressions with a one-line "force the good plan" fix
  • Missing indexes linked to the queries that need them

Where the time went, at any moment

Active sessions are sampled every two seconds and broken down by wait: CPU, IO, locks, log, memory, parallelism. Click any point to see exactly what was running and who was blocking whom.

  • Deployments, schema and setting changes marked on every chart
  • Learned baselines: alerts when something is unusual for that hour

Deadlocks you can actually fix

Deadlocks are grouped into recurring patterns, drawn as a lock graph, and explained step by step, with prevention advice for the specific pattern.

Health checks with the fix attached

Backups against your RPO, Availability Groups and geo-replication, Agent jobs, CHECKDB, capacity forecasts, configuration, security and end-of-support dates. Every problem comes with a script.

Stop paying for idle capacity

Right-sizing for elastic pools, databases, Managed Instances, VMs and RDS, based on 95th-percentile and peak load, with the monthly saving at your own rates.

Privacy and FAQ

Does any of my data leave my network?

No. There is no telemetry. The only optional connections are an update check that reads the public release list, and AI explanations if you turn them on with your own Anthropic key (literal values are masked). See the privacy statement.

What permissions does it need?

Read-only monitoring permissions: VIEW SERVER STATE / VIEW DATABASE STATE on SQL Server, pg_monitor on PostgreSQL, PROCESS and read access to performance_schema on MySQL. Scripts are included.

How much load does it add?

Light queries every 15 seconds, query statistics every minute, and heavier checks every 10 minutes or less often. Every query has a 30-second timeout, and each feature can be switched off.

Is it free?

Yes, during the beta. Beta testers will be offered a discount if a paid edition follows.

Windows warns about the download. Is it safe?

New downloads from small publishers trigger SmartScreen until they build a reputation. Compare the file's SHA-256 with the .sha256 file on the release page, then choose More info > Run anyway.
