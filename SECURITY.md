# Security policy

Please **don't** report security problems in public issues.
Email YOUR-CONTACT-EMAIL with the details (version, steps to reproduce). You'll get a reply within
5 working days, and a fix or mitigation plan as soon as possible.

Recommended deployment:
- Use the least-privilege monitoring logins from the setup scripts.
- The desktop app listens on 127.0.0.1 only. For a shared installation, turn on sign-in
  (Settings > Access) and put it behind HTTPS.
